# トレカ在庫ポートフォリオ管理

トレーディングカード（ポケモンカード／ワンピースカード／遊戯王 等）の在庫を4象限（早く売れるか×利益率が高いか）で管理するためのExcel運用テンプレート。対象はトレカのみ（フィギュア・アパレル等は非対象）。

## 使い方

`在庫ポートフォリオ管理.xlsx` を開き、まず「使い方」シートを読んでください。以下の6シートで構成されています。

1. **使い方** — シート構成、2段階の判断の仕組み、入力ルール（色分け）、用語解説
2. **設定** — 4象限のしきい値・投資フレームワーク名称/資金配分目安との対応表、銘柄タイトル（ポケカ／ワンピカ／遊戯王等）／希少性／トレンド／ボラティリティ（目減り係数）／ステータスのマスタ、偏りリスク集計用のキャラ・イラストレーター・企画/収録弾リスト
3. **ウォッチリスト** — 未仕入れのカードを登録すると自動で4象限に振り分け。資本効率・実効想定売却日数・ポジションサイズ目安も自動算出
4. **仕入れ計画** — 象限別の上限単価・許容希少性／トレンド／ボラティリティ・月間予算配分（初期値55%/20%/20%/5%）
5. **在庫管理** — 実在庫を4分類＋タグ（キャラ／イラストレーター／企画・収録弾／絶版／周年／希少性／トレンド／ボラティリティ）で登録し、ポートフォリオ比率・資本効率・実効流動性を自動計算
6. **ダッシュボード** — 資金効率（資金倍率・在庫の入れ替わり回数・含み損益率）、換金のしやすさ、攻めと守りの評価（資本効率・実効流動性）、偏りリスク（銘柄タイトル別・象限別・キャラ別・イラストレーター別・希少性帯別・企画/収録弾別、および象限別の枚数構成比）を自動集計・グラフ表示

象限（コア＝コアポジション／回転＝キャッシュ同等物／厳選＝グロース枠／見送り＝劣後在庫）は「想定売却日数」「想定粗利率」から自動判定します。カードごとに実際に仕入れてよいかは、「希少性」「トレンド（値動きの勢い）」「ボラティリティ（値動きの荒さ）」の3条件を「仕入れ計画」シートの基準と見比べて判断します。同じ象限内での優先順位は「資本効率」（攻めの評価）、保有量の抑制判断は「実効流動性・ポジションサイズ目安」（守りの評価）を使います。この2軸フレームワークと資金配分目安は、社内の投資フレームワーク検討資料（利益率×流動性マトリクス、回転率・ボラティリティによる補正）を反映したものです。

スケジュール（8月の運用タスク）はこのワークブックには含めていません。`docs/obsidian/スケジュール_8月.md` を参照してください。

## サマリーPDF・Obsidianノート

`docs/` に、全体像をまとめたシンプルなサマリーPDFと、Obsidian用のMarkdownノートがあります。

- `docs/在庫ポートフォリオ管理_サマリー.pdf` — 4象限フレームワーク・仕入れ計画・在庫管理・ダッシュボードKPIの要点（3ページ）
- `docs/obsidian/在庫ポートフォリオ管理.md` — 上記サマリーのObsidianノート版（Vaultにコピーして使用）
- `docs/obsidian/スケジュール_8月.md` — 8/3〜9/2の日次・時間帯別タスク（チェックボックス付き。在庫ポートフォリオ本体とは別管理）

再生成:

```bash
# サマリーPDF（docs/summary.html を編集してから実行）
/opt/pw-browsers/chromium-1194/chrome-linux/chrome --headless --disable-gpu --no-sandbox \
  --print-to-pdf="docs/在庫ポートフォリオ管理_サマリー.pdf" --no-pdf-header-footer \
  "file://$(pwd)/docs/summary.html"

# Obsidianスケジュールノート
python3 docs/build_schedule.py
```

## 再生成

ワークブックは `scripts/build_workbook.py`（openpyxl）から生成しています。レイアウトやしきい値のロジックを変更する場合はこのスクリプトを編集し、再実行してください。

```bash
python3 scripts/build_workbook.py
# 数式の再計算（LibreOffice必須。要 libreoffice-calc パッケージ）
python3 <xlsxスキルのscripts>/recalc.py 在庫ポートフォリオ管理.xlsx
```
