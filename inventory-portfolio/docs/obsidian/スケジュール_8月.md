# 在庫ポートフォリオ管理：8月スケジュール（8/3〜9/2）

[[在庫ポートフォリオ管理]] の実務タスク1〜4を、1か月・日次・時間帯別のタスクに落とし込んだもの。

> [!info] 基本の1日の型
> - 平日：朝会 → 作業ブロック① → 作業ブロック② → 夜の振り返り
> - 土曜：追い込みブロック（10:00-13:00）
> - 日曜：週次振り返り（19:00-19:30）のみ、基本は休み

## 進捗トラッカー

- [ ] Week1: 実務タスク1（ウォッチリスト4象限分類）完了
- [ ] Week2: 実務タスク2（仕入れ計画策定）完了
- [ ] Week3: 実務タスク3（在庫管理シート運用開始）完了
- [ ] Week4: 実務タスク4（ダッシュボード運用）完了
- [ ] Week5: 統合リハーサル・本格運用開始

## Week1（8/3〜8/9）実務タスク1：ウォッチリスト4象限分類

**ゴール**: 設定シートを確定し、スニダンのウォッチリスト登録分を全件4象限に振り分ける

### 8/3（月）
- [ ] **09:00-09:30** 朝会：今週のゴール確認（ウォッチリスト全銘柄の4象限分類を完了する）
- [ ] **10:00-12:00** 「設定」シートの4象限しきい値・カテゴリ／レアリティマスタを事業実態に合わせて確定
- [ ] **14:00-16:00** スニダンのウォッチリストを全件エクスポート
- [ ] **20:00-20:30** 振り返り：書き出し件数の確認、明日の入力対象を整理

### 8/4（火）
- [ ] **09:00-09:30** 朝会：本日の入力目標件数を設定
- [ ] **10:00-12:00** ウォッチリストシートへ銘柄データ入力（前半）
- [ ] **14:00-16:00** ウォッチリストシートへ銘柄データ入力（後半）
- [ ] **20:00-20:30** 振り返り：入力進捗の確認、情報が薄い銘柄をリストアップ

### 8/5（水）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 想定売却日数・想定粗利率が未入力の銘柄の相場を追加調査・入力
- [ ] **14:00-16:00** 自動分類（4象限）結果を全件レビューし、外れ値をチェック
- [ ] **20:00-20:30** 振り返り

### 8/6（木）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 象限別の候補数・偏りを確認し、しきい値（30日/20%）の妥当性を検証
- [ ] **14:00-16:00** しきい値調整が必要なら「設定」シートを修正し、再分類結果を確認
- [ ] **20:00-20:30** 振り返り

### 8/7（金）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 各象限の代表銘柄をピックアップし、方針との整合性を目視検証
- [ ] **14:00-16:00** ウォッチリスト運用ルール（誰が・いつ新規銘柄を追加するか）を文書化
- [ ] **20:00-20:30** 週次振り返り準備

### 8/8（土）
- [ ] **10:00-13:00** 週内に処理しきれなかった銘柄の入力・分類の追い込み

### 8/9（日）
- [ ] **19:00-19:30** 週次振り返り：実務タスク1完了確認、来週（仕入れ計画）の準備

## Week2（8/10〜8/16）実務タスク2：仕入れ計画策定

**ゴール**: 象限別の上限単価・許容属性・予算配分を確定し、仕入れ計画の運用を開始する

### 8/10（月）
- [ ] **09:00-09:30** 朝会：今週のゴール確認（仕入れ計画を確定し運用開始する）
- [ ] **10:00-12:00** 象限別「対象カテゴリ」「許容属性条件」をウォッチリスト分類結果を見ながら具体化
- [ ] **14:00-16:00** 象限別「上限仕入単価」を過去仕入実績・利益率から試算
- [ ] **20:00-20:30** 振り返り

### 8/11（火）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 月間仕入れ総予算を確定（資金繰り・在庫余力から算出）
- [ ] **14:00-16:00** 象限別の予算配分比率を仮決定し「仕入れ計画」シートに反映
- [ ] **20:00-20:30** 振り返り

### 8/12（水）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 象限別「在庫上限点数」を保管スペース・資金繰りから設定
- [ ] **14:00-16:00** ウォッチリストの仕入れ候補数と予算配分を突き合わせ、実行可能性を確認
- [ ] **20:00-20:30** 振り返り

### 8/13（木）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 仕入れ計画のドラフトをレビューし、矛盾点（予算超過等）を修正
- [ ] **14:00-16:00** 仕入れ判断フロー（誰が最終GOを出すか）を明文化
- [ ] **20:00-20:30** 振り返り

### 8/14（金）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 仕入れ計画を確定・共有
- [ ] **14:00-16:00** 象限I(コア)候補から試験的に1〜2件、計画に沿って仕入れを実行
- [ ] **20:00-20:30** 振り返り

### 8/15（土）
- [ ] **10:00-13:00** 仕入れ計画の運用ルール整備の追い込み・来週の棚卸し対象リストアップ

### 8/16（日）
- [ ] **19:00-19:30** 週次振り返り：実務タスク2完了確認、来週（在庫管理）の準備

## Week3（8/17〜8/23）実務タスク3：在庫管理シート運用開始

**ゴール**: 既存在庫を4分類＋タグで棚卸し登録し、ポートフォリオ比率と集中リスクを可視化する

### 8/17（月）
- [ ] **09:00-09:30** 朝会：今週のゴール確認（既存在庫の棚卸し登録を完了する）
- [ ] **10:00-12:00** 既存在庫の棚卸しリストアップ（保管場所・点数の洗い出し）
- [ ] **14:00-16:00** 在庫管理シートへ登録（カテゴリ・仕入値・現在時価入力、前半）
- [ ] **20:00-20:30** 振り返り

### 8/18（火）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 在庫管理シートへ登録（後半）
- [ ] **14:00-16:00** タグ付け（キャラ／イラストレーター／絶版／周年／レアリティ）
- [ ] **20:00-20:30** 振り返り

### 8/19（水）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** タグ付けの継続、「設定」シートのキャラ／イラストレーター集計リストを実データに更新
- [ ] **14:00-16:00** 想定売却日数・レアリティ等、未入力項目の埋め合わせ
- [ ] **20:00-20:30** 振り返り

### 8/20（木）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** ポートフォリオ比率・集中リスク（HHI）の初期値を確認し、異常値をチェック
- [ ] **14:00-16:00** 集中リスクが高いカテゴリ／キャラがあれば要因分析
- [ ] **20:00-20:30** 振り返り

### 8/21（金）
- [ ] **09:00-09:30** 朝会
- [ ] **10:00-12:00** 在庫データの週次更新ルール（誰が・いつ・何を更新するか）を決定・文書化
- [ ] **14:00-16:00** 在庫管理シートの運用リハーサル（新規仕入れ1件を実際に登録）
- [ ] **20:00-20:30** 振り返り

### 8/22（土）
- [ ] **10:00-13:00** 棚卸し登録の追い込み・データ精度チェック

### 8/23（日）
- [ ] **19:00-19:30** 週次振り返り：実務タスク3完了確認、来週（ダッシュボード）の準備
